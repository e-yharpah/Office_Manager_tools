### 1. إذن الاستخدام المجاني

يُسمح بتنزيل هذا البرنامج واستخدامه مجانًا للأغراض الشخصية والتعليمية والاختبارية والإدارية الداخلية، بشرط الالتزام بجميع بنود هذا الترخيص.

### 2. القيود

لا يجوز دون الحصول مسبقًا على إذن كتابي صريح من صاحب حقوق النشر:

- إعادة نشر البرنامج أو توزيعه أو رفعه أو نسخه مرآتيًا أو إتاحته عبر موقع أو مستودع أو منصة أو تطبيق أو حزمة أو رابط تنزيل آخر، سواء بصورته الأصلية أو بعد تعديله.
- بيع البرنامج أو تأجيره أو ترخيصه من الباطن أو تضمينه في حزمة مدفوعة أو توزيعه تجاريًا، بما في ذلك النسخ المعدلة منه.
- استخدام البرنامج أو شفرته المصدرية أو أي نسخة معدلة منه لتحقيق ربح مالي مباشر أو غير مباشر، أو مقابل مدفوع، أو إيراد تجاري، أو أي منفعة مادية أخرى.
- حذف أو إخفاء أو تعديل إشعارات حقوق النشر أو اسم المصمم والمبرمج أو نص الترخيص.
- ادعاء ملكية البرنامج أو نسب تصميمه أو برمجته إلى شخص أو جهة أخرى.

يُسمح بمشاركة رابط المستودع الرسمي الأصلي، ويُشجَّع ذلك.

### 3. طلب الإذن

تتطلب إعادة التوزيع أو الاستخدام التجاري أو إدراج البرنامج ضمن منتج أو خدمة مدفوعة أو أي استخدام خارج الأذونات السابقة الحصول أولًا على موافقة كتابية صريحة من صاحب حقوق النشر.

### 4. ترخيص Microsoft

لا يوفر هذا البرنامج تراخيص أو مفاتيح لمنتجات Microsoft Office، ولا يمنح أي حقوق متعلقة بمنتجات Microsoft. يجب على المستخدم استعمال تراخيص أصلية والالتزام بشروط Microsoft المعمول بها.

### 5. إخلاء المسؤولية

يُقدَّم البرنامج «كما هو» دون أي ضمان صريح أو ضمني. وفي أقصى حدود ما يسمح به القانون، لا يتحمل صاحب حقوق النشر مسؤولية أي مطالبة أو ضرر أو فقدان بيانات أو توقف خدمة أو أي مسؤولية أخرى تنتج عن البرنامج أو عن استخدامه.
