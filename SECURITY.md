# Security Policy / سياسة الأمان

## Reporting a vulnerability

Please do not publish sensitive security details in a public issue. Open a GitHub issue with only a brief, non-sensitive description and ask the maintainer for a private contact method.

Do not include product keys, account information, system identifiers, logs containing personal data, or screenshots that reveal private information.

## الإبلاغ عن ثغرة

لا تنشر تفاصيل أمنية حساسة في بلاغ عام. افتح بلاغ GitHub بوصف مختصر وغير حساس، واطلب من مسؤول المشروع وسيلة تواصل خاصة.

لا تُرفق مفاتيح المنتجات أو بيانات الحسابات أو معرّفات الجهاز أو سجلات تحتوي على بيانات شخصية أو صورًا تكشف معلومات خاصة.

## Supported version

Security fixes are applied to the latest version available on the `main` branch.
