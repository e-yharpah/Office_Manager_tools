# Contributing / المساهمة

Thank you for your interest in improving Office Manager.

شكرًا لاهتمامك بالمساهمة في تطوير Office Manager.

## Before opening an issue

- Check that the problem still occurs with the latest `Office_Manager.bat`.
- Include your Windows version, Office edition, architecture, and the exact error message.
- Never post a complete product key, email address, or other private information.
- Describe what you selected in the menus before the error occurred.

## قبل فتح بلاغ

- تأكد أن المشكلة موجودة في أحدث نسخة من `Office_Manager.bat`.
- اذكر إصدار Windows ونسخة Office والبنية ورسالة الخطأ كاملة.
- لا تنشر مفتاح المنتج كاملًا أو بريدك أو أي معلومات شخصية.
- وضّح الخيارات التي اخترتها في القوائم قبل ظهور الخطأ.

## Pull requests

1. Create a branch from `main`.
2. Keep each pull request focused on one change.
3. Test Batch changes on a supported Windows system.
4. Explain the test steps and expected result.
5. Do not add activation bypasses, unofficial keys, or third-party download sources.

## تغييرات الكود

1. أنشئ فرعًا جديدًا من `main`.
2. اجعل كل Pull Request خاصًا بتغيير واضح واحد.
3. اختبر تعديلات Batch على نظام Windows مدعوم.
4. اذكر خطوات الاختبار والنتيجة المتوقعة.
5. لا تضف طرقًا لتجاوز التفعيل أو مفاتيح غير رسمية أو مصادر تنزيل خارجية.
